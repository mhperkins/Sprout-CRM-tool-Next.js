Delivery · 2 September 2026 · Design session

The event workspace, reimagined

One screen instead of five tabs. A wireframe, a comms architecture, and the discovery that half of it was already built.

Effort: high No app code No schema change 1 new file Wireframe only

The finding that reframed everything

The events portal was already built. lib/eventPortal.js is 391 lines: nine sections, twelve required fields, a live public form, and progress functions already computing completion. It sat behind a link in the Details tab and drove nothing. The protocol every event should follow was written and invisible.

What the session decided

All comms move to Discord

One channel, forum posts per event. The server populates as a side effect of using it.

Hosts are pointed, not required

The portal stays the intake and front door. Outside hosts get sent to their thread but never have to make an account.

Build the extractor, not the integrations

Reading a conversation and reporting what changed is one step, whatever the source. Discord feeds it automatically, paste feeds it permanently.

Why not iMessage and Instagram

Discord

Works today. Bot, MCP, and read access already in place. Six members, zero forum channels so far.

Instagram DMs

Needs a Meta app review, realistically weeks and rejectable, and only ever sees the org inbox. Never personal DMs.

iMessage

Impossible from a deployed app. Apple ships no API; the only path is a local agent on the Mac that dies whenever the laptop sleeps.

What the wireframe argues

The protocol becomes the spine

Nine sections down the left, red where a required answer is missing. First thing you see is what is blocking.

Lineup carries a per-role rubric

Music gets confirmed, set time, tech needs, payout. Visual art gets confirmed, hang time, wall space, price list. So 2 of 3 musicians confirmed is computed, never typed. This is the piece that does not exist yet.

Conversations is a review queue

Each proposal shows the change, the quote it came from, and who said it. Apply or dismiss. Nothing writes itself.

Everything else demotes

The checklist calendar moves into a modal, media becomes an assets tile, and the run of show assembles from the lineup instead of being entered twice.
