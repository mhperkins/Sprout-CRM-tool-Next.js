Newsletter sections are now drag-to-reorder

Grab a ⠿ handle and drag a section above or below another. The live preview and saved draft follow.
175e38b main · pushed Effort: medium npm run build ✓ No schema / DB change

Content blocks reorder by drag. Order saves in field_values.section_order — no migration, and existing drafts render exactly as before until you move something.

Renderer (lib/newsletter.js)

  • buildCompact / buildQuickHit assemble the body from a blocks map
  • Joined in orderedBlockIds(section_order, …) order
  • Resolver dedupes saved ids, appends any missing block, ignores stale/foreign ids
  • data-sec markers move with blocks → focus↔preview scroll still syncs

Editor (CRMManager.jsx)

  • Per-field render lifted to a renderField(sec) helper
  • Sections card: fixed-top → draggable block cards → fixed-bottom
  • Native HTML5 drag — only the ⠿ handle is draggable, textareas stay usable
  • Cyan dashed highlight marks the drop target
